Cursor Usage Monitor
====================

This app shows your Cursor usage in the system tray and a small desktop widget.

INSTALL (quick)
---------------
Windows: Run CursorUsageSetup-....exe and follow the wizard.
macOS:   Open CursorUsage-....pkg and follow Installer.
Linux:   Run CursorUsageSetup-....run (allow executing if your browser saved it without execute permission).

FIRST RUN
---------
If you are logged in to cursor.com in Chrome, Edge, Brave, or Firefox, the app may import your session automatically.
Otherwise use the tray menu: Set token... (see docs/AUTH.md in the install folder or project site).

SECURITY
--------
Your session token is like a password. Do not share it.

UNINSTALL
---------
See docs/UNINSTALL.md or use Settings / Apps on Windows, remove the app on macOS, or run uninstall.sh on Linux.
